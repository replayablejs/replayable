# Sprite source assets

The PNG files below this directory are the complete canonical raster set from Kenney's
[Background Elements Remastered](https://kenney.nl/assets/background-elements-remastered),
version 1.0: 69 default-resolution objects and 20 backgrounds/layers.

Equivalent retina, spritesheet, SVG, and SWF representations from the archive are intentionally
omitted to avoid including duplicate forms of the same artwork in this standalone-image example.

The assets are released under the
[Creative Commons CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
public-domain dedication. Attribution is not required; this note is retained for provenance.

`play-button.en.png`, `play-button.hy.png`, and `install-button.en.png` are localized examples
derived from the CC0 `button_rectangle_depth_gradient.png` in Kenney's UI Pack. Their text variants
were produced with OpenAI image generation for this project. The English-only install button
intentionally demonstrates fallback selection in an Armenian build.
