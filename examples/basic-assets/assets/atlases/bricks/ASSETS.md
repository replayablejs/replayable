# Brick atlas source assets

The PNG files in this directory are the complete default-resolution set from
Kenney's [Brick Pack](https://kenney.nl/assets/brick-pack), version 2.0.

The archive also provides equivalent double-resolution PNG and SVG variants;
those are intentionally omitted to avoid packing duplicate frames into this example atlas.
Color-directory names are prefixed to the filenames so every frame has a unique key.

The assets are released under the
[Creative Commons CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
public-domain dedication. Attribution is not required; this note is retained for provenance.
