# Kenney car-kit 3.1

Selected unmodified models and texture images from [Kenney's car-kit pack](https://kenney.nl/assets/car-kit).
Licensed CC0-1.0; see the original `License.txt`.

`SOURCE.json` records the download URL, archive hash, original archive paths, and individual
file hashes. Directory prefixes were removed when copying; model contents and relative
texture references are unchanged.
