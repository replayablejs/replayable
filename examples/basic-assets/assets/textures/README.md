# Standalone Kenney texture

`kenney-blocky/texture-a.png` is the unmodified character texture from Kenney's
[Blocky Characters 2.0](https://kenney.nl/assets/blocky-characters), CC0-1.0.
See the original `kenney-blocky/License.txt` and the download/hash record in
`../models/blocky-characters/SOURCE.json`.

The same image is referenced by `models/blocky-characters/character-a.glb`.
This standalone copy demonstrates the `textures` category; the model pipeline
also embeds the referenced image in the generated character GLB.
